响应式实验室

同一个页面，容器变宽或变窄，排版会自己换一套。这一页把这件事摊开来看： 三块屏幕装着同一个文件，外加一根可以随便拖的滑杆。

01同一份代码，三种宽度Devices

下面三块屏幕里装的都是 demo.html，HTML 一个字都没改过； 只是容器宽度不同，卡片就从一列变成两列、四列，右栏也自己冒出来。

手机390 px · 单列

平板768 px · 两列

桌面1440 px · 四列 + 右栏

02拖动看看Live

拖下面的滑杆，宽度从 280 到 1440 连续变化，页面会实时重排。

620 px · 平板 · 1 列

03三条断点Breakpoints

  • ≤ 619 px 手机：卡片一列；右栏收起；导航横向滑动；标题字号收小
  • 620 – 959 px 平板：卡片两列；正文内边距加大；标题略微放大
  • ≥ 960 px 桌面：卡片四列；右栏出现（主栏 + 186 px 侧栏）；标题最大

04关键代码Code

整页响应式只靠这几行媒体查询，没有用到任何框架。

/* 卡片：默认一列 */
.cards {
  display: grid;
  grid-template-columns: minmax(0, 1fr);
  gap: 10px;
}

/* 平板：两列 */
@media (min-width: 620px) {
  .cards { grid-template-columns: repeat(2, minmax(0, 1fr)); }
}

/* 桌面：四列 + 右侧出栏 */
@media (min-width: 960px) {
  .cards { grid-template-columns: repeat(4, minmax(0, 1fr)); }
  .cols  { grid-template-columns: minmax(0, 1fr) 186px; }
  .aside { display: block; }
}
