课程笔记

课上陆陆续续记的六条，都是这个网站上真正用到的东西。

NOTE 01

标签与结构

先搭骨架，再谈样式。页头、导航、正文、页脚各归各位，屏幕阅读器也能读懂。

  • 语义标签比一堆 div 更好维护
  • 一个页面只用一个 h1
  • 图片必须写 alt
<header> 页头 </header>
<nav> 导航 </nav>
<main> 正文 </main>
<footer> 页脚 </footer>
NOTE 02

盒模型

每个元素都是一个盒子：内容、内边距、边框、外边距。宽度算错，页面就歪。

  • box-sizing 设成 border-box 更省心
  • margin 会重叠，padding 不会
  • 用 DevTools 的彩色图层看懂盒子
.box {
  width: 240px;
  padding: 16px;
  border: 1px solid #e7e0d5;
  box-sizing: border-box;
}
NOTE 03

Flex 排一行

导航条、卡片底部、图标加文字，一行里怎么对齐，交给 Flex 就好。

  • justify-content 管主轴
  • align-items 管交叉轴
  • gap 比挨个写 margin 干净
.row {
  display: flex;
  align-items: center;
  gap: 16px;
}
NOTE 04

Grid 分两栏

左栏固定、右栏自适应，是个人主页最常见的骨架，用 Grid 两行代码就够了。

  • fr 是按比例分配剩余空间
  • minmax(0, 1fr) 能防内容撑破
  • gap 同时管行距和列距
.layout {
  display: grid;
  grid-template-columns: 248px minmax(0, 1fr);
  gap: 34px;
}
NOTE 05

媒体查询

窄屏不是把字缩小，而是换一种排法。两栏变一栏，横向变纵向。

  • 断点按内容需要定，不必照抄设备
  • 先写桌面版，再用 max-width 收
  • 别忘了加 viewport 声明
@media (max-width: 760px) {
  .layout { grid-template-columns: 1fr; }
}
NOTE 06

动效

动画不是炫技，是告诉眼睛“这里变了”。幅度小、时间短，才不吵。

  • transition 管状态变化
  • @keyframes 管循环动作
  • 给 prefers-reduced-motion 留条后路
@keyframes rise {
  from { translate: 0 0; opacity: 0; }
  to   { translate: 0 -80px; opacity: 1; }
}
.cloud { animation: rise 14s linear infinite; }
