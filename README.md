# 个人网页 · faded

《计算机基础》课程设计作品。一个用 HTML / CSS 搭建的个人网站，共 5 个内容页面
（另有一张自定义 404），托管在代码仓库并通过 Pages 服务发布。

**在线地址：<https://facedes189.github.io/homework/>**
仓库：<https://github.com/facedes189/homework>（发布用） · <https://gitee.com/faded-to-perfection/faded>（源码）

## 目录结构

```
.
├── index.html        首页（主页，Pages 默认访问入口）
├── about.html        个人简介（含 4 个页内锚点、留言便签墙）
├── works.html        动画作品（4 个纯 CSS 动效，各带可拖动的旋钮与「随机一下」）
├── gallery.html      我的相册（瀑布流 6 张 + 可翻页的查看器）
├── thoughts.html     学习心得（3 篇短文，带页内目录与「接着读」）
├── 404.html          自定义 404（Pages 会在找不到页面时自动使用它）
├── css/
│   └── style.css     全站样式（含响应式与无障碍适配）
├── js/
│   └── main.js       滚动淡入、相册查看器、页脚日期、便签墙、点赞、主题切换、时段问候、彩蛋、作品旋钮、探索成就、足迹码、阅读进度环、心得页目录与续读、今日一句
└── images/           照片与图标素材
```

## 说明

- **相册**：六张原图都是正方形，按内容各给一个略作裁剪的比例（3:2 / 4:5 / 1:1），
  用 CSS 多列排成高低错落的瀑布流；进入视口时从「略大、略灰」落定，三列错开 0.08s 依次显影。
- **照片查看器**：点击或按回车打开，← → 翻页、底部缩略图直达、双击在 2.2 倍间切换（放大后按住可拖动），
  手机上左右滑动切换；Esc 或点空白关闭，关闭后焦点回到刚才那张照片。
- **页面数量**：5 个内容页面，满足"不少于 5 个"的要求；另有 1 张自定义 404。
- **主页**：`index.html`，页面内包含到其余 4 个分页面的链接（顶部导航 + 左侧栏 + 页内卡片），
  并有一块"本站一览"数据概览，进入视口时数字递增。
- **相对路径**：所有页面、样式、脚本、图片均使用相对路径，整个文件夹拷贝到任何位置、
  或整体上传到 Pages 后都能正常显示。
- **结构参考**：整体沿用传统个人主页的"页头 → 导航条 → 左栏 + 正文 → 页脚"骨架，
  配色保留红 / 蓝 / 白 / 黑，但全部用现代 CSS 重写，未引入第三方框架或 CDN。
- **动效**：四段动画均由 AI 生成，以 `@keyframes` 实现；横幅的云、气球与卡片悬停也用纯 CSS
  完成，并在 `prefers-reduced-motion` 下自动关闭。
- **响应式**：桌面两栏，窄屏自动变为单栏并先显示正文；导航在窄屏可横向滑动。
- **日 / 夜间主题**：页头右上角切换，颜色全部走 CSS 变量，选择记在 localStorage，
  刷新和跳页都不会回到日间。
- **自定义 404**：`404.html` 会渲染在用户请求的任意路径上，因此它先由脚本算出站点根目录，
  再把样式、脚本、链接改成根路径，深层地址下也不会丢样式。
- **彩蛋**：首页左栏头像连点 10 下，满屏掉一场星星雨（桌面 240 颗、窄屏 140 颗，纯 CSS 五角星）。
  头像下方有一枚会轻轻浮动的小提示「多点我几次试试」，点它同样计入连击，并实时显示「还差 N 下」；
  找到彩蛋后提示淡出，本地记一个标记，下次打开不再出现。
  星星用**负的 animation-delay** 随机错开相位、再配合无限循环，所以一出现就铺满整屏、过程中也不会越落越稀，
  约 4.6 秒后整层淡出并移除节点。
- **作品旋钮**：每件动画下面有一两个滑块，直接改 CSS 变量：地球自转与轨道速度、气球漂浮快慢、
  光带倾角与扫过速度、终端打字速度与打字内容。拖动即时生效，说明这些效果是 CSS 在跑、不是视频。
  打字内容改动后会重新量一次文字宽度，再按字数走 `steps()`，中英文都按实际宽度停住。
- **便签墙**：「写信给我」提交后不再直接弹出邮件客户端，而是在表单下方生成一张手写体便签，
  按顺序自动找空位贴好；按住可以拖动换位置，位置与内容存在 localStorage，下次打开还在。
  便签只在本机浏览器里，想真的寄到邮箱可以再点「用邮件寄一份」。
  屏幕宽度小于 640px 时只保留最近 6 张，桌面最多 9 张，最早的会让位给新的。
- **探索成就**：页脚一行六枚徽章（点赞 / 彩蛋 / 翻完六张照片 / 切换日夜 / 贴一张便签 / 走遍五个页面），
  进度写成「已解锁 3 / 6」，鼠标移上去（或键盘 Tab 到）会提示解锁方式；全部记在 localStorage，
  不需要后端，也不会影响别人看到的内容。
- **足迹码**：成就只存在本机浏览器，换台设备就是新的一张白纸。徽章右边有个「足迹码」，
  点开是形如 `…/index.html#foot=f1,like-egg,index.html-about.html` 的链接，复制到另一台设备打开，
  就把那边的进度并过来（只添不减，本机已有的不会丢）；面板里也能直接粘贴别人给的码。
  格式是 `f1,成就 id 用 - 连接,打开过的页面用 - 连接`，页面名里有点，所以两级用逗号隔开。
  读完后地址栏里的 hash 会被擦掉，刷新不会重复提示。
- **页面转场**：点导航换页时，旧页轻轻淡出、新页从下方浮上来（原生 View Transition，
  一行 `@view-transition`）。不支持的浏览器保持原来的直接跳转，等于没有这一段；
  开了「减少动态效果」的系统设置则直接切页。
- **阅读进度环**：长页面右下角一枚细环，随滚动补满；读到底闭合成勾、停两秒退场，
  往上滚回来它又出现；点一下回到顶部。可滚动距离不足 260px 的页面（比如 404）不出现。
- **作品页的「随机一下」**：一键把四件作品的旋钮摇成一组新参数，连终端那句文字也换，
  每次都不同；旁边「恢复默认」回到 1.0× / 22° 的原样。
- **心得页的目录与续读**：标题下方三枚胶囊对应三篇，滚到哪一篇就亮哪一篇，左栏那份目录一起亮；
  底色变、字重变，字色不动。点目录、或从带 `#p2` 的链接进来，先按你点的那篇亮，
  等你自己往下滚了才交还给位置判断，不会「刚点完第三篇却亮着第二篇」。
  离开时记下读到哪儿，下次进来底部浮一条「上次读到…」，点「接着读」回到原处；
  滚到底、或点「不用了」，就不留记录。记录只在本机，换设备不会跟着走。
- **今日一句**：左栏那句按天换，十二句轮着来。取的是「今天是今年第几天」，所以同一天里刷新多少次、
  换几台电脑打开，看到的都是同一句；不需要联网，也不多存一个键。关掉脚本时留下的是第一句。
- **按时段问候**：首页首屏按本地时间分成清晨 / 上午 / 午后 / 傍晚 / 深夜五段，
  问候语、小图标和卡片上方的天色光晕一起变；时段在 `<head>` 里先算好写进
  `html[data-daypart]`，首屏不会闪错，五套文案由 CSS 按属性切换，脚本只负责时钟和对时。
  关闭脚本时降级成一句中性问候。

## 本地查看

直接双击 `index.html` 即可，无需服务器。

## 发布（Pages）

> 说明：Gitee（码云）的 Pages 服务已于 2024 年下线，仓库设置里已经没有该入口，
> 因此本作品改用 GitHub Pages 发布，步骤与码云 Pages 基本一致（都是选分支 + 选根目录）。

### 路线 A：GitHub Pages（推荐，长期有效）

1. 在 GitHub 新建一个**公开**仓库，例如 `homework`。
2. 给本地仓库加一个 GitHub 远程，并把代码推上去：

   ```bash
   git remote add github git@github.com:你的用户名/homework.git
   git push github master
   ```

3. 打开仓库 `Settings → Pages`，`Source` 选 `Deploy from a branch`，
   分支选 `master`，目录选 `/ (root)`，保存。
4. 等 1–2 分钟，访问 `https://你的用户名.github.io/homework/` 即为首页。
5. 之后每次 `git push github master`，网站会自动更新。

推送前请确认根目录有 `index.html`（本仓库已满足），`.nojekyll` 用于跳过 Jekyll 处理，
避免文件名以下划线开头的资源被忽略。

### 路线 B：Netlify / Cloudflare Pages（不用账号也能先看效果）

打开 <https://app.netlify.com/drop>，把整个项目文件夹（或打包好的 zip）直接拖进页面，
几秒后即可得到一个可访问的网址；注册后可保留该地址并绑定自定义域名。

### 路线 C：只做本机演示

直接双击 `index.html` 即可完整浏览，无需服务器。
若作业要求必须提交公网地址，请使用路线 A 或 B。
